# Security Policy

## Reporting a vulnerability

Please report security issues privately rather than opening a public issue when disclosure
could put users or systems at risk.

Contact: [kontakt@me-mateescu.de](mailto:kontakt@me-mateescu.de)

Please include:

- the affected URL or component;
- a concise impact description;
- reproduction steps;
- a minimal proof of concept where necessary.

Do not include credentials or unrelated personal data, and do not perform destructive testing
against the live site.

## Scope

The current public version of the portfolio at [me-mateescu.de](https://me-mateescu.de) and the
source code in this repository are the supported scope.

## Disclosure

Please allow reasonable time for investigation and remediation before any public disclosure.
